# WP03 — The Move

## Objective

Create `datastore/` and `modelstore/`, relocate six modules, rewrite every import site named in the occurrence map, and delete the old paths.

## Context

This is the bulk edit. Ownership is deliberately broad — `src/sigil_ml/**` and `tests/**` — because splitting an import rewrite across work packages would give two of them overlapping ownership of `app.py`, `poller.py`, `routes.py` and the test modules. **This includes WP02's two new test files**, which T013 updates; that is sanctioned, not a scope violation.

Target layout (from [plan.md](../plan.md)):

```
src/sigil_ml/
├── datastore/
│   ├── __init__.py     re-exports
│   ├── protocol.py     ← store.py            DataStore, create_store
│   ├── sqlite.py       ← store_sqlite.py     SqliteStore
│   └── postgres.py     ← store_postgres.py   PostgresStore
└── modelstore/
    ├── __init__.py     re-exports
    ├── stores.py       ← storage/model_store.py   ModelStore, Local, S3, Cached
    ├── loader.py       ← loader.py                ModelLoader, FilesystemModelLoader
    └── cache.py        ← cache.py                 ModelCache
```

Read first: [plan.md](../plan.md) D-002/D-003/D-004 and §Public import surface, plus **`occurrence_map.yaml`** — that map is your checklist.

## Subtasks

### T008 — Create `datastore/`, move the three data modules

**Steps**:

1. `git mv src/sigil_ml/store.py src/sigil_ml/datastore/protocol.py`, and likewise `store_sqlite.py` → `sqlite.py`, `store_postgres.py` → `postgres.py`. **Use `git mv`** so the diff reads as a rename rather than a delete-plus-add — it is what makes this reviewable.
2. **Do not edit the contents beyond imports.** No logic change, no signature change, no default change, no docstring rewrite, no reordering (C-001, D-002). The temptation to tidy while moving is exactly what turns a safe refactor into an unreviewable one.
3. Fix intra-package imports — `sqlite.py` and `postgres.py` import the protocol, which is now a sibling.

**Files**: `src/sigil_ml/datastore/*`

**Validation**:
- [ ] `git mv` used; diff reads as renames
- [ ] No content change beyond import statements
- [ ] Intra-package imports resolve

## Risks

| Risk | Mitigation |
|---|---|
| Tidying while moving makes the diff unreviewable | T008/T009 forbid content changes; reviewer checks the diff shape |
| A shim survives and hides stale imports | T012 forbids shims and asserts `ModuleNotFoundError` |
| An import site is missed | The occurrence map is the checklist; 487 tests catch the rest loudly |
| The two caches get "helpfully" merged | C-002 forbids it — visibility is this mission's contribution, resolution is not |
| An assertion needs changing to pass | T013 makes that an escalation — it would mean behaviour changed |

## Reviewer Guidance

1. **Read the diff shape first.** It should be renames plus import lines. Any hunk changing logic inside a moved file is out of scope regardless of merit.
2. **Grep for shims** — a module whose entire body is a re-export from the new location.
3. **Check `git mv` was used**, so renames are visible as renames.
4. **Confirm the two caches are untouched.**
