# WP02 — Stack B Test Coverage

## Objective

Give `ModelCache` and `FilesystemModelLoader` their first tests — **against their current paths**, before anything moves.

## Context

These 268 lines (`cache.py` 168, `loader.py` 100) sit on the live serving path: `app.py:87` calls `self.model_cache.get(tenant_id, model_name)`. They have **zero test coverage**.

That matters for a specific reason. This mission's central claim is that the move is behaviour-preserving (FR-005, C-001), and you cannot verify that claim for code nothing tests. Written *after* the move, these tests would only prove the code works in its new home. Written *before*, they prove it behaves identically in both — which is the whole point (D-005).

**Write the tests against the current import paths** (`sigil_ml.cache`, `sigil_ml.loader`). WP03 carries them across as part of the move; that carry-across is itself evidence the move preserved behaviour.

Read first: [research.md](../research.md) D-005, [spec.md](../spec.md) User Story 3, and the two modules themselves.

## Subtasks

### T004 — `ModelCache` tests

**Purpose**: FR-008.

**Steps**:

1. Create `tests/test_model_cache.py`, importing from `sigil_ml.cache` (the current path).
2. Cover:
   - **TTL expiry** — an entry past its TTL reads as a miss, and the miss counter increments
   - **LRU eviction** — at `max_size`, adding an entry evicts the least-recently-used one
   - **Statistics** — hits, misses, evictions, and hit-rate arithmetic
   - **`evict(tenant_id)`** removes only that tenant's entries
   - **`evict_all()`** clears everything and counts correctly
   - **`cleanup_expired()`** removes expired entries and returns the count
   - **`loaded_tenants()`** reports only non-expired entries
3. Control time explicitly. `ModelCache` uses `time.monotonic()`, so patch that rather than sleeping — a test that sleeps for a TTL is slow and flaky.
4. The cache is documented thread-safe. At minimum assert concurrent `get`/`put` does not corrupt state; a full concurrency proof is not required.

**Files**: `tests/test_model_cache.py`

**Validation**:
- [ ] TTL expiry, LRU eviction, statistics covered
- [ ] Tenant-scoped and full eviction covered
- [ ] `time.monotonic()` patched, not slept
- [ ] Tests pass against the current implementation

### T005 — `FilesystemModelLoader` tests

**Purpose**: FR-009. Tenant scoping is the subtlest behaviour in this mission.

**Steps**:

1. Create `tests/test_model_loader.py`, importing from `sigil_ml.loader`.
2. Cover the documented resolution order — `{models_dir}/{tenant_id}/{model_name}.joblib`, then `{models_dir}/{model_name}.joblib`:
   - **Tenant-specific artifact wins** when present
   - **Shared fallback** applies when no tenant-specific artifact exists
   - **Cross-tenant isolation** — two tenants with different artifacts under the same model name each get their own, never the other's. Assert this by *content*, not merely by path.
   - **`None` on missing** — a missing artifact returns `None` and does **not** raise. The protocol docstring in `loader.py` states this explicitly and callers depend on it.
   - **Unreadable or corrupt artifact** — behaves per the current implementation; document what that is rather than asserting what you think it should be.
3. Use `tmp_path` for the models directory. Do not touch the real `~/.local/share/sigild/`.
4. Assert against the `ModelLoader` protocol surface, so the tests survive an implementation change.

**Files**: `tests/test_model_loader.py`

**Validation**:
- [ ] Tenant-specific preferred over shared
- [ ] Shared fallback covered
- [ ] Cross-tenant isolation asserted by content
- [ ] `None` on missing, no raise
- [ ] Real user directories untouched

### T006 — Prove the tests bite

**Purpose**: A test that passes against broken code will bless the move. That is worse than no test.

**Steps**:

1. Copy the package to a scratch location — **never modify repo source**.
2. Break each behaviour one at a time and confirm the corresponding test fails:
   - Make `get()` ignore the TTL → expiry test must fail
   - Make eviction drop the *newest* entry → LRU test must fail
   - Make the loader ignore `tenant_id` → isolation test must fail
   - Make the loader raise instead of returning `None` → missing-artifact test must fail
3. Restore the scratch copy or discard it.
4. Record which mutation each test caught, in the module docstring. A future reader should see the coverage was demonstrated, not assumed.

**Files**: `tests/test_model_cache.py`, `tests/test_model_loader.py`

**Validation**:
- [ ] Four mutations run, each caught by a named test
- [ ] Repo source never modified
- [ ] Results recorded in the module docstrings
