# WP04 — Serving Non-Regression

## Objective

Prove the serving path is unchanged. The expected production-code delta for this WP is **zero or near-zero** — it is predominantly verification, and a large diff here is a signal something went wrong.

## Context

The serving path is currently correct. `poller.py` and `routes.py` predict against *active* tasks, where "now" genuinely is now. WP01's design makes this true by construction: `as_of_ms` defaults to `None`, which means current wall clock, so existing call sites need no edit.

This WP exists because "by construction" is a claim, and FR-009 requires evidence. It is also the natural place to catch an over-eager WP01 that changed a default or made the parameter required.

Read before starting: [spec.md](../spec.md) User Story 2, [quickstart.md](../quickstart.md) §2.
