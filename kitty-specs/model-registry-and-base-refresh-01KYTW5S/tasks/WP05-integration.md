# WP05 — Integration

## Objective

Wire the registry into the code that already exists: validated loading through `FilesystemModelLoader`, retained-example capture during local training, strict vector construction in both trainers, and a manifest written on every local training run.

## Context

The registry is inert until the existing call sites use it. This is where the silent-zero corruption is actually closed — replacing `[features.get(f, 0.0) for f in FEATURE_NAMES]` with strict lookup, which is only safe because contract validation ran first.

**Mission ordering**: `feature-extraction-correctness-01KYTR7N` also owns `trainer.py` and `cloud_trainer.py`. It must be merged before this package runs. Confirm before starting.

## Subtasks

### T018 — `loader.py` uses registry validation

**Purpose**: Route model loading through slot resolution and validation.

**Steps**:

1. `FilesystemModelLoader.load()` currently resolves tenant-specific then shared-fallback paths and loads bytes. Route it through WP02's slot resolution so validation happens before deserialization.
2. Preserve the existing contract: **return `None` when no model exists, never raise** — the protocol docstring in `loader.py` states this explicitly and callers depend on it. A refused artifact behaves the same as an absent one from the caller's perspective, with the reason logged.
3. Preserve tenant resolution. Tenant-specific and shared-fallback still apply within the local slot; the base slot is not tenant-scoped.
4. Do not modify `ModelStore` or `storage/model_store.py` (D-005). The registry sits above them.

**Files**: `src/sigil_ml/modelstore/loader.py`

**Validation**:
- [ ] Loading routes through slot resolution and validation
- [ ] Returns `None` for refused artifacts, never raises
- [ ] Tenant resolution preserved
- [ ] `ModelStore` untouched
- [ ] Refusals logged with reason

### T019 — `trainer.py` retains examples and uses strict lookup

**Purpose**: FR-007 and FR-009 for local training.

**Steps**:

1. After building the training matrix, write the examples to the retained set via WP03 — vectors, labels, and the `as_of_ms` reference time each was computed at.
2. Replace `[features.get(f, 0.0) for f in FEATURE_NAMES]` with strict lookup:

```python
x = [features[f] for f in contract.names]
```

3. This is safe **only because contract validation ran first**. Add a comment saying so. A `KeyError` here means validation was skipped, which is a defect, not a data condition — do not add a defensive `.get()` back.
4. Where no contract is available — synthetic cold start with no model on disk — fall back to `FEATURE_NAMES` as the contract. Cold start does not load an artifact, so there is nothing to validate against.
5. Retention writes only on a successful training run. A failed run must not leave partial examples.

**Files**: `src/sigil_ml/training/trainer.py`

**Validation**:
- [ ] Examples retained after a successful run
- [ ] Nothing retained after a failed run
- [ ] Strict lookup, no `.get()` fallback
- [ ] Cold-start path works with no contract present
- [ ] `as_of_ms` carried through per example

### T021 — Manifest written on every local training run

**Purpose**: FR-016 and FR-015.

**Steps**:

1. After a successful local training run, write a manifest alongside the artifact with:
   - `provenance.n_local_extensions` incremented from the previous local manifest, or 1 if extending a base for the first time
   - `provenance.base_version` / `base_sha256` carried from the base being extended, if any
   - `provenance.training_source` = `local`, or `synthetic` on cold start
   - `runtime` populated from the running environment
   - `feature_contract` from the contract used
   - `training.n_samples`, `metrics` where available
   - `artifact_sha256` computed over the bytes actually written
2. **Never write to the base slot** (FR-015). Local training writes only under `models_dir()`. Assert this in the test.
3. Write artifact and manifest atomically together — a manifest whose `artifact_sha256` does not match the artifact beside it would be refused on next load, silently downgrading the install to the base model.
4. Create `tests/test_registry_integration.py` covering: manifest written with correct provenance after training; extension count increments across runs; base slot unmodified; strict lookup in use; retention populated; a failed run leaving no partial state.

**Files**: `src/sigil_ml/training/trainer.py`, `tests/test_registry_integration.py`

**Validation**:
- [ ] Manifest written on every successful local run
- [ ] Extension count increments correctly
- [ ] `artifact_sha256` matches the bytes written
- [ ] Base slot byte-identical after repeated training
- [ ] Failed run leaves no partial artifact or manifest
- [ ] `pytest tests/test_registry_integration.py` passes
